# FATIRLOGIST — разделённая версия

Запуск: откройте `index.html` (работает и локально, двойным кликом, и на любом хостинге).

## Структура
- `index.html` — каркас: шапка, меню, модальные окна, подключение скриптов
- `pages/*.js` — 19 страниц, каждая грузится только при первом открытии
  (dashboard, telegram, orders, clients, consolidated, board, loading, stock, warehouse, products,
  vehicles, logisticians, warehouseManagers, analytics, reports, notifications, audit, codes, settings)
- `js/data.js` — демо-данные · `js/core.js` — состояние, коды, утилиты, иконки, меню
- `js/actions.js` — общие действия (модалки, создание/правка заказов, клиентов, товаров, машин)
- `js/shell.js` — роутер и ленивая загрузка страниц · ссылки вида `index.html#/orders` открывают нужную страницу
- `js/theme.js` + `css/themes.css` — светлая / тёмная тема (по умолчанию как в системе, выбор запоминается)
- `js/i18n.js` + `i18n/tg.js` — русский / таджикский; словарь «русский текст → таджикский»

## Как добавить перевод
Откройте `i18n/tg.js` и добавьте строку `'русский текст':'таджикский текст'`.
Совпадение должно быть точным. Непереведённое остаётся по-русски.

## Новая страница
1. `<section id="имя" class="page"></section>` в `index.html`
2. `pages/имя.js` с функцией отрисовки
3. Запись в `PAGE_FN` (`js/shell.js`) и в `navGroups` (`js/core.js`)

## Резервирование по заводам
- Остаток хранится по заводам (`p.factories`), резерв — по заводам (`p.resBy`), сумма резервов дублируется в `p.reserved`.
- При создании заказа резерв ставится автоматически: сначала на выбранный завод (по умолчанию «Авто»), затем на любой завод, где хватает; если ни на одном не хватает — заказ делится между заводами; если не хватает суммарно — статус «Ожидание остатка», резерв не создаётся.
- Откуда зарезервировано, хранится в заказе (`o.resMap`). Отмена/удаление заказа снимает резерв; статус «Отгружен/Завершён» снимает резерв и списывает физический остаток с тех же заводов.
